## 概要

47都道府県制覇を目標とした個人旅行記録ブログ。訪問した都道府県を D3.js + TopoJSON で描画したリアルな日本地図に色分け表示し、旅行記と写真を県単位で管理・公開できる。訪問ステータスを「未訪問 / 通過 / 宿泊のみ / 訪問済み」の4段階で記録し、47都道府県の制覇進捗をビジュアルで確認できるのが特徴。

## 技術スタック

| レイヤー         | 技術                                         |
| ---------------- | -------------------------------------------- |
| フロントエンド   | Next.js (App Router) / Vercel                |
| バックエンド API | Hono / Cloudflare Workers                    |
| データベース     | Neon (サーバーレス PostgreSQL) / Drizzle ORM |
| 画像ストレージ   | Cloudflare R2                                |
| 地図描画         | D3.js + TopoJSON (SVG)                       |
| モノレポ管理     | npm workspaces + Turborepo                   |

### 構成

`apps/frontend`・`apps/backend`・`packages/shared`・`packages/db`・`packages/config` の5パッケージ構成。frontend と backend の型共有は Hono の RPC 型（AppType）を介してコンパイル時のみ行い、ランタイムは HTTP に留めることで依存を明確に分離。都道府県コードや status enum などのドメイン定数は `packages/shared` に一元管理している。
